# 프론트엔드 세미나 3주차 과제

## 개요

### 목표

스토리지, 전역 상태, 스타일링 라이브러리를 활용하여 할 일 관리 앱 '천 개의 할 일'을 구현합니다.

### 디자인

- [피그마 와이어프레임](https://www.figma.com/design/D7ExZro4wufqeZmFQfnGgv)을 참조하되, 이 디자인과 완전히 같을 필요는 없습니다.
- 스타일링에는 [Tailwind CSS](https://tailwindcss.com) 라이브러리를 사용해야 합니다.
- 필요한 경우 [shadcn/ui](https://ui.shadcn.com) 등 추가적인 도구를 사용할 수 있습니다.

### 스토리지 및 전역 상태 관리

- 스토리지는 데이터의 성격(얼마나 오래 보관해야 하는지, 언제 바뀌는지 등)을 고려하여 자유롭게 선택하세요. 저장해야 하는 데이터는 아래와 같습니다.
  - 진행 중인 할일 목록(제목·카테고리·생성일·완료 여부)
  - 작성 중인 할일 입력값(모달에서 아직 저장 전인 내용)
  - 완료한 할일 보관함(제목·카테고리·생성일·완료일)
  - 다크 모드 여부
- 전역 상태 관리 방법도 자유롭게 선택하세요. `useContext`, [Zustand](https://zustand-demo.pmnd.rs), [Redux](https://redux.js.org) 등 무엇을 쓰든 상관없습니다.
- 선택한 스토리지와 전역 상태 관리 방법을 각각 왜 골랐는지 과제 제출 시 PR 본문에 간단히 적어서 함께 제출해 주세요. 각각 2~3줄 정도면 충분합니다.


## 구현 상세

### (1) 메인 화면

- 새로고침해도 진행 중인 할 일 목록이 그대로 유지되어야 합니다.
- 카테고리 필터(전체/공부/운동/집안일)를 누르면 해당 카테고리의 할 일만 보여야 합니다.
- 체크박스를 누르면 체크 표시 & 할 일 제목에 취소선이 그어지고, '보관하기' 버튼이 표시됩니다.
- '보관하기'를 누르면 목록에서 사라지며 생성일·완료일과 함께 보관함으로 옮겨집니다.
- 우측 하단 + 버튼을 누르면 할 일 추가 모달이 열립니다.
- (선택) 보관함에서 날짜로 검색하거나 정렬하는 기능을 추가하면 좋습니다. 

### (2) 할 일 추가/수정

- 제목을 입력하고 카테고리를 선택한 뒤 저장하기를 누르면 메인 목록에 새 항목이 추가됩니다.
- 저장 전의 작성 중인 내용은 모달을 닫았다 다시 열어도 남아있어야 합니다.
- 취소를 누르면 작성 중이던 내용 없이 모달만 닫혀야 합니다.
- (선택) 기존 할 일을 클릭하면 같은 모달이 수정 모드로 열리도록 합니다.

### (3) 설정

- 다크 모드
  - 다크 모드 토글을 누르면 앱 전체(메인/모달/설정 화면 전부)가 즉시 다크 모드로 바뀌어야 합니다.
  - 다크 모드 여부는 새로고침해도, 브라우저를 껐다 켜도 유지되어야 합니다.
- 보관함
  - 보관함 열기를 누르면 완료된 할일 목록(제목·카테고리·생성일·완료일)을 볼 수 있어야 합니다.
  - (선택) 보관함에서 완료일 기준으로 검색하거나 정렬하는 기능을 추가합니다.
- 초기화
  - 초기화를 누르면 저장된 모든 데이터(할일 목록·보관함·다크모드 설정)가 삭제되어야 합니다.


## 주요 명령어

- `yarn dev` — 개발 서버를 실행합니다.
- `yarn check-all` — 타입, 포맷, 미사용 코드 검사를 실행합니다.
- `yarn build` — 프로덕션 빌드를 생성합니다.
